UBER_LOG 公式取込

Uber Web から取得 → 内容を確認 → UBER_LOG へ反映 → 自動テスト → 保存（HANDOFF・commit・push）を1本道で進めます。
押すのは「次にやること」の緑のボタンだけです。

この画面はPCのローカル専用です。デスクトップの「UBER_LOG」から開いてください。

    Uber Web のログイン

    取得には【Phase 1専用Edge】で Uber にログインしている必要があります（普段の Edge とは別のウィンドウ・ログイン状態は保持されます）。

    スクショで取り込む（従来の方法・Uber Web で取得できないとき）

    Uberアクティビティ一覧を貼り付け、Delivery詳細のスクショを全部入れてから「スクショで取り込む」を押します。
